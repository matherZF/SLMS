## 一、当前架构要点（已核对代码）

| 项 | 现状 |
|---|---|
| 后端 | Spring Boot 3.2.5，Java 17，端口 8080，包名 `wms-backend` |
| 建表方式 | Flyway（`backend/src/main/resources/db/migration`），`ddl-auto: validate`，空库首次启动自动建表 |
| 登录鉴权 | JWT，**必须设置环境变量 `JWT_SECRET`（≥32 字节），否则启动直接失败** |
| 前端 | Vue + Vite，构建产物 `frontend/dist/`，API 走 `/api` 相对路径 → 需 nginx 反代到 8080 |
| CORS | 已允许 `http://10.*.*.*:*`，23 上部署无需改 |
| 安卓 APP | Capacitor，`allowNavigation` 已含 `10.*.*.*`，指向 23 无需重打包 |
| 外部数据源 | 设备日统计默认启用：DT(`.33` MySQL)、WMS(`.25` MySQL)、WCS(`.22` Oracle) |

## 四、风险提示

1. **24 是测试库服务器**：把生产 SP 数据放测试服务器有风险，确认该机器的备份与稳定性能满足生产要求；若后续有正式库服务器，迁移只需改 `APP_DB_URL`。
2. **外部源密码在配置文件默认值里**：包会被分发（如拷到服务器、留档），建议尽快改环境变量。
3. **Windows 2016 服务器同时承担"远程桌面"角色**：注意 8080/80 端口占用冲突与资源争用，上线前 `netstat -ano | findstr ":80 :8080"` 检查一遍。
